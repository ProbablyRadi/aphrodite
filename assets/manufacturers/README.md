# Manufacturer badge sources

Badges are local PNG assets, displayed beside manufacturer names in race
classifications. Original marks remain the property of their respective owners.

Thirteen badges are from the thumbnail collection in
[Car Logos Dataset](https://github.com/filippofilip95/car-logos-dataset), retrieved
25 October 2026: Toyota, BMW, Peugeot, Alpine, Ferrari, Porsche, Cadillac,
Lamborghini, Aston Martin, Chevrolet Corvette, Lexus, McLaren and Ford.
Source files: `https://raw.githubusercontent.com/filippofilip95/car-logos-dataset/master/logos/thumb/{slug}.png`.
The dataset describes its code as MIT licensed; that does not transfer trademark
or logo rights. No additional software from the repository is bundled.

The Isotta Fraschini badge is the official website icon, retrieved on the same date:
https://isottafraschini.com/wp-content/uploads/2023/06/cropped-favicon-1-192x192.png
